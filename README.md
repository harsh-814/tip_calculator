# Tip Calculator

A simple Python project that calculates how much each person should pay after splitting a bill, including tip percentage.

## Features
- Takes total bill amount as input
- Asks for tip percentage
- Splits the total bill among multiple people
- Displays how much each person should pay

## Concepts Used
- Variables
- User Input
- Type Conversion
- Arithmetic Operations
- Rounding Numbers

## Example

Welcome to the tip calculator!
What was the total bill? $150
What percentage tip would you like to give? 10
How many people to split the bill? 5

Each person should pay: $33.0
